Model connection

Endpoint is intentionally configurable because the provided HTML files had no actual local-model runtime.

Expected response: { class, confidence } or { predictions: [...] }.
What the dashboard does now:
1. Upload/camera → POST image to your local API.
2. API returns class + real model confidence.
3. Medical is flagged and excluded from sorted total.
4. Weight comes from manual input until a real weighing sensor is connected.
